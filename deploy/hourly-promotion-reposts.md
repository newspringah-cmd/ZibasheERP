# یادآوری پروموشن ساعتی

کران یک‌دقیقه‌ای موجود، `flash-sale-promotion.py` نصب‌شده را اجرا می‌کند. هر پروموشن دارای رسید انتشار گروه، تا وقتی فعال و دارای موجودی باشد، هر ۹۰۰ ثانیه یک عکس تبلیغ با لینک خرید، قیمت تخفیف‌خورده، تایمر و باقی‌ماندهٔ تازه در همان گروه می‌فرستد. کانال بازنشر دوره‌ای ندارد. کپشن همهٔ نسخه‌های منتشرشده تا پایان به‌روز می‌شود؛ انقضا یا پایان زودهنگام دکمه خرید را غیرفعال می‌کند. این رفتار تغییری در قیمت‌گذاری، درخواست‌ها و فاکتورها نمی‌دهد.

ساعت سکوت `00:00 <= Asia/Tehran < 06:00` است و فقط انتشار مجدد را متوقف می‌کند. ویرایش تایمر و پیام پایان طبق روال قبلی ادامه دارد. بعد از سکوت یا قطعی، حداکثر یک پیام ارسال می‌شود و فاصلهٔ بعدی از رسید همان پیام محاسبه می‌شود؛ پیام‌های عقب‌افتاده انباشته نمی‌شوند.

رسیدها در `~/.local/state/zibashe-flash-sales/<campaign-id>/reposts/<slot>/` ذخیره می‌شوند. همهٔ اجراها قفل `run.lock` مشترک با انتشار ادمین دارند. نتیجهٔ نامعلوم ارسال عکس، انتشارهای بعدی همان پروموشن را برای بررسی متوقف می‌کند تا پیام تکراری ساخته نشود. خطای قطعی HTTP قابل تلاش مجدد است؛ `retry_after` تلگرام رعایت می‌شود. رسید یادآوری، شناسهٔ پست اصلی پروموشن در API را عوض نمی‌کند.

در نصب یا استقرار، فایل `deploy/flash-sale-promotion.py` باید با حفظ دسترسی اجرایی جایگزین `~/.local/bin/zibashe-flash-sale-promotion.py` شود. نیازی به تغییر کران یا راه‌اندازی مجدد API نیست. بک‌آپ فایل قبلی و همسانی نسخهٔ مخزن و فایل نصب‌شده کنترل شود.

تست‌های مستقل از شبکه:

```sh
python3 deploy/tests/flash-sale-promotion.test.py
python3 deploy/tests/admin-promotions.test.py
```
