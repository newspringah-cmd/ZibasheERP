# بستهٔ اجرای وب مستقل زیباشی

نسخهٔ ۱٫۰، ۱۸ نوامبر ۲۰۲۶. مبنا: کد `a4e27a8` و نیاز ادامهٔ عملیات با اینترنت داخلی برای حدود ۱۰۰۰ مشتری فعال.

- [دفترچهٔ کامل فارسی](handbook.fa.md): معماری، قواعد، مراحل، آزمون، انتشار، مهاجرت و بازگشت، همراه ۱۹۰ قابلیت.
- [رجیستر قابلیت‌ها](capability-register.csv): فایل UTF-8 BOM برای Excel؛ قابلیت‌ها هنوز «برنامه‌ریزی‌شده» هستند. مسئول و شاهد هنگام اجرا تکمیل شوند.
- [دروازه‌های اجرا](execution-gates.csv): ده مرحله و شروط عبور و بازگشت و محل ثبت تصمیم.
- [نسخهٔ ساختاریافته](capability-register.json): تصویر رجیستر در نسخهٔ تهیهٔ دفترچه؛ پس از ویرایش CSV باید دوباره تولید شود.

این بسته سند برنامه‌ریزی است و هیچ مجوز خودکار برای تغییر production، جابه‌جایی دیتابیس یا تغییر نقش کاربران ایجاد نمی‌کند. هر ادعای تکمیل وب به شاهد مستقل نیاز دارد. فایل‌های PDF و HTML خودکفا در بستهٔ تحویلی قرار دارند؛ برای انتشار کتاب روی فضای عمومی باید سیاست اشتراک‌گذاری مستند فنی بررسی شود.

برای ویرایش بعدی، CSV مرجع پیگیری قابلیت‌ها و Markdown مرجع بخش‌های معماری و اجراست. از `render.py` برای هماهنگ‌کردن پیوست و تولید نسخه‌های خروجی استفاده کنید. نیازها: Python 3 با بستهٔ WeasyPrint 68.1 و کتابخانه‌های Pango موردنیاز آن، Pandoc و فونت Noto Sans Arabic. این ابزار به سرور ERP، دیتابیس یا تلگرام متصل نمی‌شود.

```bash
python3 docs/web-continuity/render.py --output /tmp/zibashe-handbook-output
```
