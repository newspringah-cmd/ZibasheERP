# آماده‌سازی مستقل پیش‌نمایش — ۱۸ نوامبر ۲۰۲۶

با دستور مدیر «تهیهٔ زیرساخت را جز کارها بگذار، بعد می‌خرم؛ ادامه بده»، فعالیت مستقل و غیرتولیدی ادامه یافت. [کارهای مدیر](../../owner-tasks.fa.md) ثبت شدند. این دستور به معنی تأیید هزینهٔ Backblaze، خرید مقصد داخلی، انتقال داده یا عبور gate بازیابی نیست.

## پیاده‌سازی این گام

`web/preview` یک پوستهٔ مستقل فارسی و راست‌به‌چپ و موبایل‌محور دارد: لیست عطرها، موجودی آماده، نمونهٔ حساب مشتری، گفت‌وگو و صف کارکنان. جست‌وجو، جابه‌جایی فضا و جزئیات در دادهٔ مصنوعی کار می‌کنند. قیمت و بدهی و شمارنده و بطری‌های شماتیک ساختگی‌اند. ورودی پیام و ثبت سفارش غیرفعال‌اند؛ ورود و مجوز واقعی نیز هنوز پیاده نشده‌اند.

این گام نمونهٔ تعاملی برای بررسی چیدمان است و برنامهٔ نهایی Next.js یا ERP کامل وب نیست. منطق تجاری ربات به آن منتقل نشده و نباید در production یا `/admin` فعلی کپی شود. فایل‌های ظاهری و الگوهای نمایش برای رابط اصلی قابل استفاده‌اند.

سرور کوچک فقط روی loopback و GET/HEADِ فایل‌های مشخص کار می‌کند؛ POST/PUT/PATCH/DELETE، مسیر API، traversal و فایل‌های داخلی رد می‌شوند. تنظیم اتصال دیتابیس و Production در شروع رد می‌شود و همهٔ flagها خاموش‌اند. هیچ startup یا migration برنامه اصلی اجرا نمی‌شود. CSP ارتباط شبکهٔ frontend را مسدود می‌کند. نسخهٔ HTML قابل دانلود هم فقط همین داده‌های ساختگی را دارد.

## شواهد

- ۴ آزمون خودکار ایمنی سرور: محیط تولید/اتصال DB و flag نامعتبر و نوشتن HTTP و افشای فایل رد می‌شوند.
- ۱۳ بررسی واقعی مرورگر: کارت‌ها، جست‌وجو، جزئیات، موجودی نیم‌میل نمونه، برچسب غیرواقعی حساب و کارکنان، عدم اتصال خارجی/ERP، ورودی غیرفعال و نبود سرریز افقی موبایل.
- بررسی تصویری دسکتاپ ۱۴۴۰×۱۰۰۰ و موبایل ۳۹۰×۸۴۴ انجام شد. مشکل min-width موبایل اصلاح و بررسی‌ها دوباره موفق شدند.
- بررسی نحوی JavaScript موفق؛ هیچ تغییر در API یا schema یا داده یا تنظیمات تولید انجام نشد.

کار بعدیِ مستقل: طراحی و آزمون قرارداد اتصال هویت و API فقط‌خواندنی با حساب‌های مصنوعی و کنترل نقش در محیط جدا. ورود نوشتنی واقعی همچنان تابع gateهای دفترچه است؛ خرید زیرساخت و بازیابی واقعی در کارهای باز مدیر باقی‌اند. این گام، اثبات عملکرد هنگام قطع اینترنت بین‌الملل نیست.
