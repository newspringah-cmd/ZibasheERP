# اصلاح تم پیش‌نمایش طبق درخواست مدیر

نسخهٔ قبلی با الگوی نزدیک‌تر به پیام‌رسان تلگرام جایگزین شد: sidebar چت، آواتار دایره‌ای، حالت انتخاب آبی، پس‌زمینهٔ طرح‌دار محلی، header گفتگو و پیام سنجاق‌شده، حباب سفید ورودی و سبز خروجی با پاسخ و ساعت، دکمه‌های زیر پیام و ورودی پایین صفحه. در موبایل نوار تب حذف و ناوبری فهرست چت/ورود به چت با دکمهٔ برگشت فراهم شد.

۲۳ بررسی مرورگر روی desktop و عرض‌های ۳۲۰،۳۹۰،۷۴۰ موفق‌اند؛ ۴ آزمون ایمنی HTTP و syntax جاوااسکریپت نیز موفق بودند. نمایش موبایل و دسکتاپ تصویری بازبینی شد. فایل SVG فقط از مسیر allowlist سرور خوانده می‌شود و CSP اتصال خارجی/ERP را باز نکرده است.

این تغییر فقط روی پیش‌نمایش مستقل است؛ ورود امن، نقش واقعی، ذخیره پیام، رسید خوانده‌شدن، خرید یا پرداخت پیاده نشده‌اند. داده‌ها و وضعیت چت ساختگی‌اند. سیستم فعال، دیتابیس و تنظیم بک‌آپ/هزینه تغییری نکرده‌اند. پرچم‌های عملیاتی همچنان خاموش‌اند و gateهای دفترچه بازند.
