# کارهای مدیر — وب مستقل و بک‌آپ داخلی

به درخواست مدیر در ۱۸ نوامبر ۲۰۲۶، تهیهٔ زیرساخت برای بعد ثبت شد. هیچ خرید یا افزایش سقف هزینه انجام نشده است.

- [ ] انتخاب و تهیهٔ فضای ذخیره‌سازی مستقل داخل ایران؛ پیشنهاد اولیهٔ پایلوت دیتابیس ۵۰ GiB، قیمت نیازمند استعلام رسمی.
- [ ] تعیین پنل ارائه‌دهنده و تأیید بودجهٔ ذخیره، انتقال و نسخه‌ها؛ مکان داده داخل ایران باید مشخص باشد.
- [ ] پس از تهیه، bucket آزمایشی خصوصی و کلید محدود از مسیر امن تنظیمات آماده شوند؛ کلید در چت/Git وارد نشود.
- [ ] تهیه یا تعیین مقصد محاسباتی ایزوله داخل ایران برای بازیابی واقعی؛ اجرای restore روی SQL فعال منظور نیست.
- [ ] تعیین تکلیف سهمیه Backblaze؛ پیشنهاد ۰٫۰۱ دلار روزانه هنوز تأیید نشده و اجرا نشده است.

تا آماده‌شدن این موارد، توسعه و آزمون مستقلِ غیرتولیدی ادامه می‌یابد. انتقال writer، خرید وب روی دادهٔ واقعی و تأیید gate بازیابی همچنان وابسته به شواهد دفترچه‌اند. وجود بک‌آپ محلی، شکست مشاهده‌شدهٔ آپلود خارج سرور را برطرف نمی‌کند.
